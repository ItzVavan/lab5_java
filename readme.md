### Подзадание 3

#### Текст задачи

Даны упорядоченные списки L1 и L2. Вставить элементы списка L2 в список L1, не нарушая его упорядоченности.

#### Алгоритм решения

1. В классе `Task3ListMerger` (`Task3ListMerger.java`) создать обобщённый метод `insertIntoSorted(List<T> l1, List<T> l2)` для любых сравнимых элементов `T extends Comparable<? super T>`.
2. Проверить оба списка на `null`.

4. В цикле перебрать каждый элемент `item2` из списка `L2`:
   * Продвигать `it1` вперёд, пока не встретится элемент `item1`, для которого `item2.compareTo(item1) <= 0`.
   * Найдя нужную позицию, выполнить шаг назад (`it1.previous()`) и вставить `item2` перед `item1` с помощью `it1.add(item2)`.
   * Если курсор дошёл до конца `L1` и все элементы оказались меньше `item2`, дописать `item2` в конец `L1` через `it1.add(item2)`.
5. В результате исходный список `L1` оказывается модифицирован «на месте» с сохранением сортировки за один проход.

## Задание 4. Мап

### Подзадание 3

#### Текст задачи

На вход программы подаются сведения о результатах соревнований по школьному многоборью. Многоборье состоит из соревнований по четырем видам спорта, участие в каждом из которых оценивается баллами от 0 до 10 (0 баллов получает ученик, не принимавший участия в соревнованиях по данному виду спорта). Победители определяются по наибольшей сумме набранных баллов. Известно, что общее количество участников соревнований не превосходит 100.

В первой строке вводится количество учеников, принимавших участие в соревнованиях, N. Далее следуют N строк, имеющих следующий формат:
`<Фамилия> <Имя> <Баллы>`

Здесь `<Фамилия>` — строка, состоящая не более чем из 20 символов; `<Имя>` — строка, состоящая не более чем из 15 символов; `<Баллы>` — строка, содержащая четыре целых числа, разделенных пробелом, соответствующих баллам, полученным на соревнованиях по каждому из четырех видов спорта. При этом `<Фамилия>` и `<Имя>`, `<Имя>` и `<Баллы>` разделены одним пробелом.

Примеры входных строк:
```text
Иванова Мария 5 8 6 3
Петров Сергей 9 9 5 7
```

Напишите программу, которая будет выводить на экран фамилии и имена трех лучших участников многоборья. Если среди остальных участников есть ученики, набравшие то же количество баллов, что и один из трех лучших, то их фамилии и имена также следует вывести. При этом имена и фамилии можно выводить в произвольном порядке.

#### Алгоритм решения

1. Создать класс-модель `Athlete` (`Athlete.java`), хранящий фамилию, имя, массив из 4 оценок и их сумму `totalScore`. В конструкторе проверять, что передано ровно 4 оценки в диапазоне от `0` до `10`.
2. В `Task4Processor.findTopAthletes(String filename)` (`Task4Processor.java`) открыть входной файл `task4_input.txt` в кодировке UTF-8 через `Files.newBufferedReader(...)` в блоке `try-with-resources`.
3. Считать первую строку (очистив от возможного символа BOM `\uFEFF`), распарсить количество участников $N$ и проверить условие $1 \le N \le 100$.
4. В цикле прочитать $N$ непустых строк, разбить каждую по пробелам (`split("\\s+")`), проверить наличие 6 частей, ограничения длины фамилии ($\le 20$) и имени ($\le 15$), распарсить 4 балла и создать объекты `Athlete`.
5. Поместить участников в отсортированную по убыванию ключей карту `TreeMap<Integer, List<Athlete>>` (`Comparator.reverseOrder()`), где ключ — сумма баллов, а значение — список спортсменов с этой суммой (заполнение через `computeIfAbsent`).
6. Перебрать списки участников из `scoreMap.values()` сверху вниз, добавляя каждую группу целиком в итоговый список `topAthletes`, и прервать цикл (`break`), как только `topAthletes.size() >= 3`. Таким образом, в ответ попадут 3 лучших участника и все, кто набрал с ними одинаковый балл.

Необходимо написать стрим:
Дан набор объектов типа `Point`, необходимо взять все `Point` в разных координатах, убрать с одинаковыми X,Y, отсортировать по X, отрицательные Y сделать положительными и собрать это все в ломаную (объект типа `Polyline`)

Если раннее в вашем варианте не было задание с классом `Point` и `Polyline`, то написать их:

   * Координата X: число.
   * Координата Y: число.
   * Может возвращать текстовое представление вида `"{X;Y}"`.
2. класс `Line` (Линия), расположенная на двумерной плоскости, которая описывается:
   * Координата начала: Точка
   * Координата конца: Точка
   * Может возвращать текстовое представление вида `"Линия от {X1;Y1} до {X2;Y2}"`
3. класс `Polyline` (Ломаная), которая будет представлять собой ломаную линию. Ломаная линия представляет собой набор следующих характеристик:
   * Имеет массив Точек, через которые линия проходит.
   * Может быть приведена к строковой форме вида `"Линия [T1,T2,...,TN]"`, где `TN` это результат приведения к строке Точки с номером N.

#### Алгоритм решения

1. Реализовать геометрические сущности:
   * `Point` (`Point.java`) — хранит координаты `x`, `y`, переопределяет `equals()` и `hashCode()` (необходимы для работы `.distinct()` в стриме) и `toString()` вида `"{X;Y}"`.

   * `.distinct()` — удалить одинаковые точки.
   * `.sorted(Comparator.comparingDouble(Point::getX))` — отсортировать точки по возрастанию координаты $X$.

#### Текст задачи

```text
Вася:5
Петя:3
```

Номера людей могут повторяться. У каких-то людей может не быть номера.
Необходимо написать стрим выполняющую следующее:
читаются все люди из файла, все имена приводится к нижнему регистру, но с первой буквой в верхнем регистре, убираем из перечня всех людей без номеров, а имена оставшихся группируются по их номеру:
