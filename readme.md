# Задание 3. Список

## Задача 1

### Текст задачи

Даны упорядоченные списки L1 и L2. Вставить элементы списка L2 в список L1, не нарушая его упорядоченности.

### Алгоритм решения

1. Разработать обобщенный статический метод слияния списков `mergeSorted(List<T> l1, List<T> l2)`, где элементы списка реализуют интерфейс `Comparable`.
2. Инициализировать результирующий список `List<T> result` и два индексных указателя $i = 0$, $j = 0$ для списков `L1` и `L2` соответственно.
3. В цикле, пока $i < |L1|$ и $j < |L2|$:
   * Сравнить элементы через `l1.get(i).compareTo(l2.get(j))`.
   * Меньший (или равный) элемент добавить в `result` и сместить соответствующий указатель на 1 вправо.
4. Добавить оставшиеся элементы непустого хвоста одного из списков в конец результирующего списка.
5. Алгоритм выполняется за линейное время $O(|L1| + |L2|)$ без использования повторной общей сортировки.

# Задание 4. Мап

## Задача 1

### Текст задачи

На вход программы подаются сведения о результатах соревнований по школьному многоборью. Многоборье состоит из соревнований по четырем видам спорта, участие в каждом из которых оценивается баллами от 0 до 10 (0 баллов получает ученик, не принимавший участия в соревнованиях по данному виду спорта). Победители определяются по наибольшей сумме набранных баллов. Известно, что общее количество участников соревнований не превосходит 100.
В первой строке вводится количество учеников, принимавших участие в соревнованиях, N. Далее следуют N строк, имеющих следующий формат:
<Фамилия><Имя><Баллы>
Здесь «Фамилия» строка, состоящая не более чем из 20 символов; «Имя» строка, состоящая не более чем из 15 символов; <Баллы> строка, содержащая четыре целых числа, разделенных пробелом, соответствующих баллам, полученным на соревнованиях по каждому из четырех видов спорта. При этом «Фамилия» и «Имя», «Имя» и «Баллы» разделены одним пробелом.
Примеры входных строк:
Иванова Мария 5 8 6 3
Петров Сергей 9 9 5 7
Напишите программу, которая будет выводить на экран фамилии и имена трех лучших участников многоборья. Если среди остальных участников есть ученики, набравшие то же количество баллов, что и один из трех лучших, то их фамилии и имена также следует вывести. При этом имена и фамилии можно выводить в произвольном порядке.

### Алгоритм решения

1. Создать класс-сущность `Athlete` с полями: фамилия, имя, массив из 4 баллов и предрассчитанная сумма баллов (`totalScore`).
2. Организовать чтение данных из текстового файла `task4_input.txt` с помощью `BufferedReader`. Первую строку распарсить как целое число $N$.
3. Каждую из последующих $N$ строк разделять по пробельным символам, валидировать диапазон баллов $[0; 10]$, инкапсулировать данные в объекты `Athlete`.
4. Для распределения по призовым местам использовать структуру `Map<Integer, List<Athlete>>`, конкретно `TreeMap` с компаратором обратного порядка `Comparator.reverseOrder()`, где ключом является сумма баллов, а значением — список участников с таким результатом.
5. Итерироваться по `Map.Entry` дерева и извлекать списки спортсменов для первых трех уникальных значений баллов (уровней рейтинга). Это гарантирует включение всех участников, разделивших 1-е, 2-е и 3-е места.
